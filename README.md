# Jellyfin Folder Collections

[![Jellyfin](https://img.shields.io/badge/Jellyfin-10.10.7-blue)](https://jellyfin.org)
[![.NET](https://img.shields.io/badge/.NET-8.0-purple)](https://dotnet.microsoft.com)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)

一个 Jellyfin 插件：**按物理文件夹结构自动生成媒体集合**，并从文件夹名中提取标签、自动设置封面。适合个人媒体库、无刮削资源的分类整理，让 Jellyfin 的搜索和筛选能按文件夹结构精准定位内容。

当前版本：**v1.0.9**

---

## ✨ 功能特性

### 核心

- **文件夹驱动**：扫描媒体库的物理目录，每个文件夹生成一个集合。
- **多级路径拼接**：`Captures\2024\春节\video.mp4` → 集合 `Captures-2024-春节`。
- **超长名称保护**：拼接后超过设定长度时，保留前缀 + `-` + 名称 SHA256 前 8 位，保证不同文件夹不会被错误合并。
- **增量同步**：只增删差异成员，不做全量重建；无变化时集合保持 `Unchanged`。
- **自动清理**：媒体库里删掉的文件夹，下次扫描自动清理对应集合（只删插件自己创建的）。
- **自动封面**：创建集合时取首个有缩略图的媒体项作为封面，已有封面不覆盖。
- **元数据锁定**：集合 `IsLocked = true`，避免 Jellyfin 去 TMDb 等在线服务拉取导致扫描卡顿。

### 标签提取

从文件夹名的**每一级目录**提取标签，支持 7 种规则，每种独立开关：

| 开关 | 语法 | 示例 | 提取结果 |
|------|------|------|----------|
| `#` 标签 | `#` 后接内容，遇括号/其它符号停止 | `#教程`、`#A #B` | `教程`；`A`、`B` |
| `@` 标签 | `@` 后接内容，遇空格停止 | `教程@入门` | `入门` |
| `{}` | 花括号，内容可含空格 | `{高清 收藏}` | `高清`、`收藏` |
| `[]` | 方括号，内容可含空格 | `[高清 收藏]` | `高清`、`收藏` |
| `【】` | 中文方括号，内容可含空格 | `【高清 收藏】` | `高清`、`收藏` |
| `()` `（）` | 中英文圆括号，内容可含空格 | `(2024 春节)` | `2024`、`春节` |
| 无符号普通词 | 剥离以上标签后拆分剩余内容 | `#A #B aa bb` | `A`、`B`、`aa`、`bb` |

提取逻辑是"先符号、后普通词"：每种格式按 `# → 圆括号 → 花括号 → 方括号 → 【】 → @` 的顺序依次提取，命中片段会从字符串中挖空，因此不会重复提取，嵌套写法也能拆开：

| 文件夹名 | 标签 |
|----------|------|
| `#实滨瑞希(実浜みき)` | `实滨瑞希`、`実浜みき` |
| `【教程(入门)】` | `教程`、`入门` |
| `[A (B)]` | `A`、`B` |

**拆词与清洗规则**

- 分隔符：空白（含全角空格）、`,` `，`、`、`、`;` `；`、`:` `：`。所以 `A、B` → `A`、`B`。
- **句点不是分隔符**：`123.ui`、`v1.0.9` 会完整保留为一个标签。
- 两端会被剥离的字符：各种括号、中英文引号、书名号、句读符、破折号、下划线。所以 `[教程`、`教程]`、`#教程，`、`“2024春节”`、`《星际穿越》` 都能得到干净标签。
- 标签必须包含字母或数字，纯符号不会成为标签。

### 可观测性

- **状态终端**：配置页内嵌实时面板，可看进度条、当前阶段、当前媒体库、集合计数、新增/更新/删除统计，以及滚动的控制台日志（保留最近 100 条）。
- **计划任务**：出现在 `控制台 → 计划任务 → Folder Collections 扫描`，可手动触发、可自定义定时规则，触发时显示 Jellyfin 原生进度条，支持取消。
- **REST 状态查询**：`GET /FolderCollections/Status` 返回结构化快照，方便外部监控。

### 触发方式

| 方式 | 说明 |
|------|------|
| 配置页「立即扫描」 | 后台异步执行，页面自动展开状态终端 |
| 计划任务 | 手动执行，或按自定义定时规则自动执行 |
| 媒体库扫描后自动同步 | 受配置开关控制，可在媒体库扫描结束后自动跑一次 |
| 服务器启动时自动扫描 | 受配置开关控制，启动 60 秒后触发，避开启动期 IO 高峰 |

四个入口共享同一把并发锁：只要有扫描在跑，其它入口会直接跳过（REST 返回 `409`），不会排队、不会并发写数据库。

## 📦 安装

### 方式一：从 Release 安装（推荐）

1. 打开 [Releases](https://github.com/normally4680/jellyfin-plugin-foldercollections/releases) 下载最新 `.zip`。
2. 解压到 Jellyfin 的插件目录，形成如下结构：
   ```
   plugins/
   └── FolderCollections/
       ├── Jellyfin.Plugin.FolderCollections.dll
       └── meta.json
   ```
   Windows 常见路径：`%LOCALAPPDATA%\jellyfin\plugins\` 或 `%ProgramData%\Jellyfin\Server\plugins\`；
   自定义安装（如 `D:\Jellyfin\Data`）则为 `Data\plugins\FolderCollections\`。
3. 重启 Jellyfin。

### 方式二：添加插件仓库

在 `控制台 → 插件 → 存储库` 添加：

```
https://github.com/normally4680/jellyfin-plugin-foldercollections/releases/latest/download/manifest.json
```

> 该 manifest 由发布工作流随每个 Release 生成，只包含当前最新版本，可用于一键安装/升级，但看不到历史版本。

### 方式三：从源码编译

```bash
git clone https://github.com/normally4680/jellyfin-plugin-foldercollections.git
cd jellyfin-plugin-foldercollections

dotnet build -c Release
# 产物位于 bin/Release/net8.0/
```

把 `Jellyfin.Plugin.FolderCollections.dll` 连同 `meta.json` 放入 `plugins/FolderCollections/`，重启 Jellyfin。

## 🚀 使用

### 1. 配置

`控制台 → 插件 → Folder Collections → 设置`：

| 配置项 | 默认 | 说明 |
|--------|------|------|
| 选择需要扫描的媒体库 | 空 | 只处理勾选的媒体库 |
| 覆盖已存在的同名集合 | 关 | 开启后每次扫描全删全加重建；**改过标签规则想批量回填时用一次，之后务必关掉** |
| 服务器启动时自动扫描 | 开 | 启动 60 秒后执行一次 |
| 自动删除不再需要的集合 | 开 | 清理媒体库中已消失的文件夹对应集合 |
| 媒体库扫描完成后自动同步集合 | 开 | 挂在媒体库扫描后置任务上 |
| 集合名最大字符长度 | 80 | 0 = 不限制 |
| 7 个标签提取开关 | 全开 | 见上方标签规则表 |

> 关于「覆盖已存在的同名集合」：日常扫描务必**关闭**。增量模式下插件仍会补齐缺失的标签、封面与锁定状态；只有在文件夹重命名或标签规则变更、需要整体重算时，才临时开启一次。

### 2. 触发扫描

- 配置页点 **立即扫描** —— 页面自动展开状态终端。
- 或到 `控制台 → 计划任务 → Folder Collections 扫描` 手动运行（有原生进度条，可取消）。
- 或勾选自动同步，让它在媒体库扫描后自己跑。

### 3. 查看进度

配置页点 **查看扫描状态 / 记录**，随时打开面板（扫描中每秒轮询刷新）：

```
[10:24:42] [进度 42.0%] [4/5 创建集合] 媒体库 1/2：家庭视频，集合 320/2150 | 新增 120 更新 80 删除 0
```

扫描阶段与进度权重：

| 阶段 | 进度区间 | 内容 |
|------|----------|------|
| 1/5 查询媒体项 | 0 → 20% | 全库分页读取候选媒体项（5000/批，按 Id 去重） |
| 2/5 筛选媒体库 | 20 → 25% | 按媒体库物理路径前缀匹配 |
| 3/5 分组标签 | 25 → 35% | 按目录层级分组、提取标签 |
| 4/5 创建集合 | 35 → 95% | 创建/增量更新集合、写标签与封面、锁定元数据 |
| 5/5 清理过时 | 95 → 100% | 删除已不存在的集合 |

### 4. 查看结果

Jellyfin 首页 → **集合**。集合页前端有 10~30 秒缓存，`Ctrl + R` 可立即刷新；改过配置页后建议 `Ctrl + F5` 强刷。

## ⚙️ 技术细节

### 执行链路

```
FolderCollectionService.RunAsync
 ├─ 并发锁（SemaphoreSlim）→ 已在跑则返回 AlreadyRunning
 └─ ExecuteScanCoreAsync
     ├─ 1/5 全库分页查询（Movie/Episode/Video/Photo/MusicVideo/Audio/Trailer）
     ├─ 2/5 按 PhysicalLocations 前缀筛选
     ├─ 3/5 相对路径 → 目录层级 → "-" 拼接 → 截断保护 → 标签提取
     ├─ 4/5 CreateOrUpdateCollectionAsync
     │    ├─ 不存在 → CreateCollectionAsync
     │    ├─ 存在 + 覆盖 → 全删全加
     │    └─ 存在 + 增量 → 差集增删
     └─ 5/5 CleanupObsoleteCollectionsAsync
```

### 写入可靠性

- 成员变更后延迟 300ms，等 Jellyfin 内部首次 XML 保存完成。
- 标签、锁定状态、封面**合并为一次** `UpdateToRepositoryAsync`，减少文件竞争。
- 写盘后读取 `collection.xml` 校验 `LockData = true`，失败按 200/400ms 退避重试，最多 3 次；仍失败会输出明确错误日志。

### 集合识别标记

只清理被判定为插件创建、且本次扫描未再生成的集合。判定满足任一条件即可：

1. 标签包含 `FolderCollections`
2. `Overview` 包含 `[FolderCollections]`
3. 集合名含 `-` 且长度 > 8（兼容早期版本创建、当时未打标记的集合）

### 关键类

| 类 | 作用 |
|----|------|
| `Plugin` | 插件主类（GUID `3f2504e0-4f89-11d3-9a0c-0305e82c3301`） |
| `PluginConfiguration` | 配置模型 |
| `FolderCollectionService` | 扫描、分组、标签、集合写入、清理、状态上报 |
| `ScanState` | 状态快照（进度/阶段/计数/最近 100 条日志） |
| `FolderCollectionScheduledTask` | 计划任务 `FolderCollectionScan` |
| `FolderCollectionPostScanTask` | 媒体库扫描后置任务 |
| `StartupScanHostedService` | 启动后延迟 60 秒的自动扫描 |
| `FolderCollectionsController` | REST API |

### REST API

| 端点 | 方法 | 权限 | 说明 |
|------|------|------|------|
| `/FolderCollections/Scan` | POST | 管理员 | 后台启动扫描；`202` 已启动，`409` 已在运行，`404` 插件未加载 |
| `/FolderCollections/Status` | GET | 管理员 | 返回状态快照（含 `recentLogs`） |

## 🐛 故障排查

**集合显示 `NotSupported`**

- 确认 DLL 是 `net8.0` 编译产物（不是 `net10.0`），且 `meta.json` 的 `targetAbi` 为 `10.10.7.0`。

**点「立即扫描」返回 409**

- 已有扫描在运行。展开状态终端查看进度；或到计划任务页取消后重试。

**集合数量远小于预期**

- 对比日志中 `媒体库 "..." 匹配到 X 个媒体项` 与该库实际数量。
- 用 SQLite 工具打开 `library.db` 核对：
  ```sql
  SELECT COUNT(*) FROM TypedBaseItems WHERE Path LIKE '%你的文件夹名%';
  ```
- 注意：媒体库根目录下**直接存放**的文件不会生成集合（没有子文件夹可命名）。

**集合没有封面或标签**

- 确认视频缩略图已生成（Jellyfin 提取需要时间）。
- 前端缓存，`Ctrl + R`。
- 日志中搜 `已保存并验证集合`，确认写入成功。

**标签太多 / 太杂**

- 关掉「提取无符号的普通词汇」。该开关会把文件夹名里每个空格分隔的词都变成标签。

**扫描耗时长**

- 首次全量扫描可能几分钟到数十分钟，取决于媒体库规模。
- 之后走增量同步会快很多。
- 每个集合都要单独查询一次以判定是否存在，集合数量极大时这一步是主要开销。

## ⚠️ 已知限制

- **取消勾选媒体库会连带删集合**：清理是按"本次扫描生成的集合名全集"比对的，把某个库从配置里去掉后，该库此前生成的集合会在下次扫描被判为过时并删除。
- **兜底识别规则可能误伤**：名字含 `-` 且长度 > 8 的**手动创建**集合（如 `Star Wars-Original`）会被当作插件集合参与清理。
- **跨库同名文件夹会合并**：两个媒体库存在同名文件夹时，会指向同一个集合，内容以最后处理的库为准，而不是取并集。
- **逗号/顿号会被当分隔符**：`1,000` 会拆成 `1`、`000`；命名里若有千分位之类写法，建议换个分隔字符。
- **首尾句点会被剥离**：`.cache` 会变成 `cache`（句点在词中间不受影响，`123.ui` 完整保留）。
